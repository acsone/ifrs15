To use this module, you need to:

1. Confirm a Sales Order containing a service product configured to auto-create a Performance Obligation and a Project.
2. Go to **Project** and select the generated project.
3. Open or create a **Project Update**:
   - Set the **Title** of the update.
   - Set the **Date**.
   - Set the **Progress** percentage.
4. Save the Project Update.
5. From the Project's Sales Order, you can navigate to the Performance Obligation using a smart button:
   - A draft accounting recognition entry has been automatically created for the progress percentage of the total obligation amount, dated as of the project update date and named after the update title.

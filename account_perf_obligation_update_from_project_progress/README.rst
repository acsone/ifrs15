This module integrates project tracking with IFRS 15 Performance
Obligations (``account_perf_obligation`` and
``account_perf_obligation_sale``). It automatically computes and posts
revenue recognition entries whenever a Project Update is created or
modified.

Based on the completion progress percentage reported on the Project
Update, the module calculates the cumulative amount to recognize:
total_amount \* (progress / 100), and triggers the recognition entry
using the Project Update date and name.

Use Cases / Context
===================

In project-based businesses (e.g., fixed-price service contracts,
software implementations, or engineering projects), revenue recognition
frequently follows the percentage-of-completion method. When a project
manager publishes a project status update, accounting needs to recognize
the corresponding portion of income. Manually calculating and creating
these recognition journal entries is repetitive and prone to
discrepancies between project management and accounting.

Usage
=====

To use this module, you need to:

1. Confirm a Sales Order containing a service product configured to
   auto-create a Performance Obligation and a Project.
2. Go to **Project** and select the generated project.
3. Open or create a **Project Update**:

   - Set the **Title** of the update.
   - Set the **Date**.
   - Set the **Progress** percentage.

4. Save the Project Update.
5. From the Project's Sales Order, you can navigate to the Performance
   Obligation using a smart button:

   - A draft accounting recognition entry has been automatically created
     for the progress percentage of the total obligation amount, dated
     as of the project update date and named after the update title.
